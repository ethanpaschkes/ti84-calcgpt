# CalcGPT

A general-purpose AI chat on the TI-84 Plus CE (school, maths, writing, coding, everyday questions). You type on the calculator; a
model answers, and the reply streams onto the calculator screen as it is written. The **Trace** key picks the model: a local one
that runs on the Mac through Ollama (private, nothing leaves the Mac, slower) or a cloud one (faster; your questions are sent to the
cloud company and each answer costs money). Answers are asked to be short, plain text, with maths written the calculator way
(`sin(30) = 1/2`).

- `src/` - the calculator program (`make` here, needs the CE C toolchain). `chatmodel.c` holds the conversation, word wrapping and
  scrolling with no drawing code, so it can be tested on a computer. `typing.c` and `typing_tables.h` are the same typing layer
  as the browser (Alpha = letters, 2nd = one-shot shift); the table is generated by `../browser/tools/gen_typing_tables.py`.
- `mac/models.json` - the models on the Trace menu (label, `ollama` or `openai` provider, model name; up to 8, labels 19 characters).
  A cloud entry needs `OPENAI_API_KEY=...` in `mac/.env` (copy `mac/.env.example`; `.env` is never committed). Check which cloud model names
  your account has with `python3 mac/calcgptd.py --list-cloud`; the default `gpt-5-mini` is a guess, edit it to a name that list shows.
  An entry may also set `base_url` (any OpenAI-compatible service) and `reasoning_effort`.
- `mac/calcgptd.py` - the Mac side. Local models need Ollama running with the model pulled (default `qwen3.8:27b`; use `--model NAME`).
  It will not run the model while a Blender or Apex Sky render is running (`--ignore-render` overrides). The model leaves memory two
  minutes after the last answer (`--keep-alive 10m` keeps it longer). The first answer after that takes up to a minute while the model loads.

Run: send `CALCGPT.8xp`, start it on the calculator, then `python3 mac/calcgptd.py`.
Keys: Enter sends, Up/Down and Window/Zoom scroll, Del erases, Graph starts a new chat, Y= stops an answer, Trace picks the model
(Up/Down, Enter), Clear erases the line then quits.

Tests (no calculator, no model needed): `python3 mac/test_calcgptd.py` and `python3 tests/test_calcgpt.py` (needs clang).
Status: works on a real TI-84 Plus CE, over the USB cable and wirelessly through the ESP32-S3 bridge (`../wireless/ESP_SETUP.md`).
